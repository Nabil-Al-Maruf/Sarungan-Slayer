## 📖 Latar Belakang & Kisah (Story Lore)

Di tengah hiruk pikuk Kota Pahlawan, kedamaian Kampung Tambak dan Warkop Kopi Giras terusik! Sekelompok geng preman dan wabah Zombie Suroboyo yang dipimpin oleh **Raja Sarung Baja Suramadu** mencuri Kendi Kopi Pusaka dan Sarung Sakti Leluhur.

Sebagai **Cak Bima** bersama arek-arek Suroboyo lainnya (**Bagus**, **Dimas**, **Raka**, dan **Yudi**), kamu bangkit berbekal sarung sakti dan pecutan maut untuk membasmi gerombolan lawan dari Gang Tambak, Jalan Tunjungan, hingga jembatan ikonik Suramadu!

---

## 🎮 Mode Permainan Utama

### 1. ⚔️ Story Mode (Petualangan 3 Babak)
Jelajahi alur cerita beat 'em up klasik dengan pertarungan boss bertahap:
- **Babak 1 • Gang Tambak & Kenjeran:** Basmi gerombolan Bocil Sarung & Preman Tambak, taklukkan *Cak Koordinator*.
- **Babak 2 • Kawasan Jalan Tunjungan:** Tembus blokade gerobak tahu tek & hadapi *Jagoan Tunjungan*.
- **Babak 3 • Jembatan Suramadu (Malam):** Duel final di atas jembatan legendaris merebut kembali pusaka dari *Raja Sarung Baja*!

### 2. 🛡️ Survival Mode (Warkop Defense — 4 Arah)
Pertahankan **Pos Ronda & Warkop Pusat** dari kepungan zombie tak terbatas:
- **Wave 1–30:** Serbuan datang dari 3 arah (Kiri, Atas, Kanan) dengan rintangan dan barikade pertahanan.
- **Wave 31+ (Simpang Empat Maut Joyoboyo):** Map khusus 4 arah (Kiri, Atas, Kanan, Bawah)! Serangan datang dari segala penjuru dengan 4 barikade yang harus dijaga.
- **Upgrade Bangunan & Barikade:**
  - Barikade Level 1–4 (Level 4 dilengkapi duri berduri yang membalas damage ke musuh!).
  - Upgrade Nyawa Warkop (Core HP).
  - Tameng Pelindung Warkop (Shield 250 HP berdurasi 1 wave).
  - Menara Mercon Otomatis di atap pos warkop.
- **Distribusi Hadiah Adil:** Uang receh hasil kill menara, barikade, dan tameng dibagi merata ke seluruh pemain tim!
- **Milestone Jurus Tiap 10 Wave:** Pilih 1 dari 4 Jurus Ultimate Sakti tiap kelipatan 10 wave tanpa menimpa kartu buff atribut 2-wave!

### 3. 🥋 Dojo Latihan (Camp Sandbox & Jurus Tester)
Arena latihan bebas untuk menguji kombo kibasan sarung, pantulan proyektil pecut, serta dock pengujian instan untuk mencoba 4 Jurus Ultimate dengan bar energi 100% tanpa batas cooldown.

## 🕹️ Panduan Kontrol & Gameplay

### Keyboard (PC / Laptop)
| Tombol | Fungsi |
|---|---|
| `W`, `A`, `S`, `D` / `Tombol Panah` | Bergerak 8-Arah |
| `Space` | Lompat (Bisa Double Jump 2x di udara) |
| `Shift` / `L` | Dash Ngeles Cepat (Menerobos celah musuh) |
| `J` / `Z` | Kibas Sarung (Kombo Serangan Jarak Dekat) |
| `K` / `X` | Pecut Sarung (Tembakan Jarak Jauh) |
| `U` / `C` | Jurus Ultimate (Ketika Bar ULT 100%) |
| `B` | Buka Warung / Toko Survival |
| `Esc` | Menu Pause / Jeda |
| `1` - `4` | Ganti Jurus Instan (Khusus Dojo Latihan) |

### Layar Sentuh / Smartphone (Mobile & Tablet)
- **360° Ergonomic Virtual Analog Thumbstick:** Navigasi jari halus dengan feedback getaran mikro (*haptic tick*) saat menyentuh batas analog.
- **Thumb Action Arc Pad:** Tata letak melengkung ramah jempol untuk tombol KIBAS, LOMPAT, DASH, PECUT, BADAI ULT, dan WARUNG.
- **Console-Grade Controller Haptics:** Dilengkapi getaran fisik berbeda untuk setiap aksi: hentakan kibas, sentakan ganda dash, getaran cambuk, serta rumble bertingkat saat jurus ultimate aktif!
- **Auto Landscape & Fullscreen:** Otomatis menyesuaikan orientasi mendatar untuk kenyamanan bermain maksimal.

## 👥 Mode Mabar Multiplayer (Multi-Device)

Game ini mendukung mabar lokal maupun jarak jauh tanpa instalasi aplikasi tambahan:

1. **Online Cloudflare Edge (WSS):**
   - Host membuat Room (mendapatkan 4 digit kode unik, misal: `LNZB`).
   - Teman memasukkan kode room di perangkat masing-masing untuk langsung bergabung.
2. **Couch Co-op Monitor + HP Stick Controller:**
   - Jadikan Laptop, Komputer, atau Smart TV sebagai **Monitor Utama**.
   - Pemain lain cukup scan **QR Code** di layar monitor menggunakan kamera HP / Google Lens.
   - HP otomatis masuk sebagai gamepad controller dengan dashboard status darah & bar ult di layar HP!
3. **Local Hotspot / Bluetooth Tethering:**
   - Mabar di tempat tanpa kuota/sinyal internet menggunakan sambungan Hotspot Wi-Fi langsung.

## 🚀 Arsitektur & Teknologi

- **Game Engine:** Pure HTML5 Canvas 2D & TypeScript — Tanpa dependensi game engine pihak ketiga (Unity/Godot/Phaser).
- **Zero-GC Pool Pipeline:** Tidak mengalokasikan objek closures per frame di loop render, mencegah lag garbage collection, dan stabil di **60–90+ FPS** bahkan pada perangkat kentang (*budget devices*).
- **Akselerasi GPU:** Canvas dikonfigurasi dengan `alpha: false`, `desynchronized: true`, serta isolasi CSS hardware composite layer.
- **Audio Synthesizer:** Real-time Web Audio API Procedural PCM Sound Synthesizer tanpa file audio eksternal yang lambat dimuat.
- **Multiplayer Backend:** Cloudflare Pages Functions + Durable Objects WebSocket (`GAME_ROOM`) dengan transmisi delta snapshot 20 Hz terkompresi.
